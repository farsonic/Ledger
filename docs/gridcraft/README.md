# GridCraft reference documents

These files are copies of GridCraft's own documentation (function parity, gaps and the parity
checklist), kept here as the reference Ledger is compared against. They are by the ArtCraft Team and
the GridCraft contributors, under the MIT licence (`LICENSE-MIT` in this folder); GridCraft also offers
them under Apache-2.0. Ledger's own comparison is `../gridcraft-gap.md`.

Taken from GridCraft at commit 4c388df (2026-11-18); `functions.txt` lists the names in its function
registry and the evaluator's special forms (RAND, RANDARRAY, RANDBETWEEN, NOW and TODAY aside).
